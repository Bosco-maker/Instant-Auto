# Roadrunner Integration

### Concept
Instant Auto is built on top of Roadrunner 1.0. The framework uses Roadrunner for all pathing, localization, and trajectory execution. The `MecanumDrive` class (generated by Roadrunner) is the central hub for movement.

### Example
**MecanumDrive Usage**: In `AutonomousBase.java`, the `MecanumDrive` is initialized with the starting pose parsed from the text file. It is then passed to the `ActionManager` to enable movement commands (like `DRIVE_TO`) and to `ActionUtils` for trajectory fusion.

**File**: `TeamCode/src/main/java/org/firstinspires/ftc/teamcode/opmodes/AutonomousBase.java`

```java
// Initialization phase
mecanumDrive = new MecanumDrive(hardwareMap, startingPose);
actionManager.init(mecanumDrive, telemetry);
```

### Expected Outcome
Users get the full power of Roadrunner's pathing algorithms while using a simplified text-based interface.
