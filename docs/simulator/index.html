InstantAuto Simulator Guide

Actions

STRAFE.TO(x, y, heading) - Move robot in straight line to target pose

STRAFE.TO(24, 24, 90)

Can also reference a pose variable:

scorePose = pose2d(48, 48, 0)
STRAFE.TO(scorePose)

SPLINE.TO(x, y, heading, startH, endH) - Move along smooth curved path

SPLINE.TO(48, 48, 90, 0, 90)

Can also reference a pose variable:

SPLINE.TO(scorePose, 0, 90)
  • startH - Path tangent angle at start (degrees)
  • endH - Path tangent angle at end (degrees)

Variables

Define variables anywhere in the script. Types are inferred automatically:

TypeSyntaxExample
double3.14wheelDiameter = 3.14
int42loopCount = 42
string"text" or 'text'robotName = "Champion"
booleantrue / falseisBlue = true
Pose2dpose2d(x, y, h)startPose = pose2d(-60, -60, 0)

Required: Starting variable must be defined as a pose2d.

Starting = pose2d(-60, -60, 0)

Conditionals

if / else if / else blocks with boolean conditions:

isBlue = true
if (isBlue) {
    STRAFE.TO(24, 0, 0)
} else {
    STRAFE.TO(-24, 0, 0)
}

Conditions are case-insensitive and can be literals or variables.

Field Coordinates

  • Field: 144" × 144" (12ft × 12ft)
  • Origin (0,0) at field center
  • +X = Right, +Y = Up
  • Heading: 0° = +X, 90° = +Y, 180° = -X, 270° = -Y
